# AirBnB Clone - Web Framework

## Description
This module implements a Flask web application as part of the AirBnB clone project.
It demonstrates routing, templating with Jinja2, and database integration using SQLAlchemy.

## Requirements
- Python 3.4+
- Flask
- MySQLdb
- SQLAlchemy

## Installation
```bash
pip3 install flask --break-system-packages
```
